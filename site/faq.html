Questions

Does DisplayControl change real brightness or just dim the picture?

Both are available and it tells you which is in use. Over DDC it changes the monitor's real backlight. If a monitor does not answer, it uses software dimming, which darkens the picture but not the backlight. The badge on each display card shows the mode.

Is it really free?

Yes. It is open source under the MIT License. There is no trial, no account and no licence key.

Does it connect to the internet?

No. The app contains no networking code, no analytics and no crash reporting. The only things that touch the network are you, when you download a release or open a link.

Will it work with my monitor?

Most monitors made in the last decade support DDC/CI, but support varies. Run displaycontrol probe to see what your Mac exposes, and displaycontrol selftest to test a monitor. The compatibility page lists what has been tested.

It says the monitor is not confirming changes. What does that mean?

After each change DisplayControl reads the value back. If the monitor reports something different, you get this hint. The usual causes are a locked picture mode (switch the monitor to Custom) or DDC/CI being turned off in the monitor's own menu.

Do docks, hubs and KVM switches work?

Sometimes. Many pass DDC through, many cheap ones block it. Try the monitor connected directly to see whether the dock is the problem.

Does HDMI work on Apple Silicon?

It worked in our test on one Apple Silicon MacBook. Others have reported DDC over HDMI failing on some Macs. If it fails for you, try USB-C or DisplayPort. The app falls back to software dimming automatically.

Does it work on Intel Macs?

Partly. Built-in and Apple displays and software dimming work. DDC for third-party monitors is only implemented for Apple Silicon.

Which macOS versions does it need?

macOS 13 or later.

Why does it want Accessibility permission?

Only for the optional brightness and volume keys. macOS requires that permission to read those keys. Everything else works without it, and you can leave it off.

The keys stopped working after I rebuilt the app.

macOS ties the permission to the app's code signature, and ad-hoc signing changes it on each build. Remove DisplayControl from System Settings, Privacy and Security, Accessibility, then add it again.

Do the keys still control my laptop screen?

Yes. DisplayControl only takes the keys when the pointer is on an external display it can control. Otherwise macOS handles them as usual.

What happens to software dimming if the app crashes?

macOS can leave the gamma table as it was. Relaunch the app, or run displaycontrol reset-gamma, or log out and in. On a normal quit, on SIGTERM and on SIGINT the app restores every display.

Can I control volume?

If the monitor has speakers and reports the control. DisplayControl hides controls the monitor does not report instead of showing ones that do nothing.

Why does my monitor ignore the contrast slider?

Many monitors lock contrast in some picture modes. The self-test reports it, and the card shows the hint.

Can I turn a monitor off and on?

You can send the power command. Some monitors cannot be woken over DDC once off, so switching its input from the Mac or pressing its button may be needed.

How do schedules deal with sleep?

If the Mac was asleep at a scheduled time, the most recent missed time-based schedule runs once on wake, but only if it was within the last two hours.

How are sunrise and sunset calculated?

On your Mac with the standard NOAA equations, from latitude and longitude you type in or allow once. Nothing is looked up online.

A monitor resets when I reconnect it. Can I fix that?

Make a preset and a schedule with the trigger Monitor connects. The preset is applied each time it appears.

Can I use it from Shortcuts, Siri or Spotlight?

Not natively yet. Use the URL scheme (open "displaycontrol://preset/Evening") or the command line from a Shortcuts "Run Shell Script" action. Native actions are not implemented.

Can an AI assistant control my monitors?

Yes, through the MCP server: displaycontrol mcp. It can read and set displays and apply presets. Turning a display off needs an explicit confirmation.

Is there a Windows version?

No.

What about Samsung and LG smart monitors?

Not supported yet. Those use network protocols rather than DDC.

Where are my settings stored?

In ~/Library/Application Support/DisplayControl/ as JSON files, written safely with a backup copy.

How do I uninstall it?

Quit the app, delete it from Applications, and delete the folder above. If you installed the command, delete /usr/local/bin/displaycontrol.

How do I report a bug?

Open an issue on the project page and paste the output of About, Copy diagnostics.
