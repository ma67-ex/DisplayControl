Compatibility

Whether DDC works depends on the Mac, the cable, anything between them and how well the monitor implements the standard. This page lists only what has actually been tested.

Add your monitor

  1. Open DisplayControl and run displaycontrol probe in Terminal.
  2. Run displaycontrol selftest "Your monitor name". It nudges brightness by three points and restores it.
  3. Open an issue on the project page with the monitor model, Mac model, cable or dock, and both outputs.

What usually goes wrong

  • Picture modes. Game, Movie and similar presets can lock brightness or contrast. Switch the monitor to a Custom mode.
  • DDC/CI turned off. Some monitors have a menu switch for it.
  • Docks, hubs, KVMs and adapters. Cheap ones often block the signal.
  • Some Apple Silicon ports. Others have reported DDC failing over HDMI on certain Macs. If that happens to you, try USB-C or DisplayPort. DisplayControl falls back to software dimming on its own.
  • Intel Macs. Hardware DDC is not implemented for Intel. Software dimming and Apple displays work.
