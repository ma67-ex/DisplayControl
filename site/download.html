Download

DisplayControl is free. Build it yourself, or download a release from the project page.

Releases on GitHubSource code

Each release lists a SHA-256 checksum. Compare it with shasum -a 256 DisplayControl.zip before opening the app.

Install

  1. Unzip DisplayControl.zip and drag DisplayControl to your Applications folder.
  2. Open it. Builds that are not notarized by Apple show a warning the first time: right-click the app, choose Open, then confirm.
  3. Look for the display icon in the menu bar. There is no Dock icon.
  4. Optional: in Settings, turn on the keyboard keys and install the displaycontrol command.

Build from source

git clone https://github.com/OWNER/DisplayControl.git
cd DisplayControl
./Packaging/build-app.sh
open dist/DisplayControl.app

Needs the Swift toolchain (Command Line Tools are enough). The script tries the newest macOS SDK first and falls back to older ones if the SwiftUI macro plugin is missing.

Requirements

  • macOS 13 or later.
  • Apple Silicon for hardware (DDC) control of third-party monitors. Intel Macs can use Apple-display control and software dimming.
After rebuilding the app yourself: macOS ties the Accessibility permission to the app's code signature, and ad-hoc signing changes it on every build. If the keyboard keys stop working, remove DisplayControl from the Accessibility list and add it again.
