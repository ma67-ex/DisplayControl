Keyboard

Brightness and volume keys

Settings, Keyboard, then turn on the brightness and volume keys. macOS asks for Accessibility permission because that is the only way to read those keys.

  • The keys control the display under the mouse pointer. A setting makes them control every display instead.
  • If the pointer is on the built-in screen, or on a display DisplayControl cannot control, macOS handles the key as usual.
  • Each press changes the value by the display's step size (1, 2, 5 or 10, in Settings, General).
If you rebuild the app, macOS may forget the permission because the code signature changed. Remove DisplayControl from the Accessibility list and add it again.

Custom shortcuts

In Settings, Keyboard, click a row, then press the keys. A shortcut needs at least one modifier (⌃ ⌥ ⇧ ⌘) so it can never block normal typing. Escape cancels and Delete clears.

Available actions: brightness up and down, contrast up and down, volume up and down, mute, cycle input and toggle sync. Each preset also has its own shortcut in its editor. Custom shortcuts do not need Accessibility permission.
