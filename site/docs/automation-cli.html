Automation and CLI

Command line

Install it from Settings, Command Line, or run the command shown there. DisplayControl must be running. Add --launch to start it if it is not.

displaycontrol status
displaycontrol list
displaycontrol get "Acer" --brightness
displaycontrol set "Acer" --brightness 70 --contrast 50
displaycontrol set --all --brightness 40
displaycontrol set "Acer" --input hdmi2
displaycontrol preset list
displaycontrol preset activate "Evening" --delay 5
displaycontrol schedule list
displaycontrol sync enable "Acer"
displaycontrol mode "Acer" software
displaycontrol selftest "Acer"
displaycontrol probe
displaycontrol reset-gamma

Pick a display by name (partial is fine), --index N or --uuid KEY. Output is readable in a terminal and JSON when piped; force either with --human or --json.

Exit codeMeaning
0Success
1Bad usage
2DisplayControl is not running
3Display or preset not found
4The display refused, or a self-test failed
5Partial success (some preset items skipped)

probe works without the app. selftest --mock runs the whole pipeline against a simulated monitor.

URL scheme

open "displaycontrol://preset/Movie%20Night"
open "displaycontrol://set?display=Acer&brightness=60"

From Shortcuts, use a Run Shell Script or Open URLs action. From AppleScript: do shell script "open 'displaycontrol://preset/Evening'".

AI assistants (MCP)

DisplayControl includes a Model Context Protocol server over stdio. Add it to your assistant's configuration:

{ "mcpServers": { "displaycontrol": { "command": "/usr/local/bin/displaycontrol", "args": ["mcp"] } } }

Tools: list and get displays, set displays, list and activate presets, set sync, list schedules and enable or disable one. Values are limited to 0 to 100, and turning a display off needs confirm: true.

The control channel is a Unix socket in your Application Support folder, readable only by you. There is no network listener.
