Presets

Creating a preset

Set your displays up the way you like, open Settings, Presets, and choose Save current setup. Then Edit it and keep only what you want it to change. Nothing is included unless it is ticked.

Can storeNotes
Brightness, contrast, volume, mutePercentages.
Input sourceSwitch a monitor between computers.
Power, rotationWhere the monitor supports them.
Resolution and refresh rateThrough macOS display modes.
PositionThe arrangement of displays.
SyncOn or off, and the host.

Applying

Choose a preset in the window, press its shortcut, run it from a schedule or use the command line or URL scheme. Items apply in a fixed order: position, control mode, resolution, rotation, power, input, then mute, brightness, contrast and volume. A display that is not connected is skipped and reported, and the rest still applies.

A delay can wait a few seconds first, which helps monitors that need time to wake.

displaycontrol preset activate "Evening" --delay 5
open "displaycontrol://preset/Evening"
