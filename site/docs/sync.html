Sync

How it works

Turn sync on from the header of the window. The first external display becomes the host (or the built-in display if there is none). To use a different host, run displaycontrol sync enable "Name", or press the toggle-sync shortcut while the pointer is on that display. Changes to the host's brightness, contrast or volume are copied to every follower.

  • Sync follows only controls the follower supports. A built-in screen has no volume, so it ignores volume changes.
  • Sync goes one way, host to followers. Moving a follower on its own does not change the host.
  • Followers are updated at the same time, each through its own queue, so three displays take about as long as one.

Offsets

100 percent on one display rarely looks like 100 percent on another. Open a follower's expanded card and set When host is 100%, for example 70. Other values scale in proportion: host 50 becomes follower 35.

In presets

A preset can include the sync state. When it turns sync on, that happens after the values are applied; when it turns sync off, before.
