Getting started

Install

Drag DisplayControl to Applications and open it. If macOS warns that the app is from an unidentified developer, right-click it, choose Open and confirm once. It has no Dock icon: look for the display symbol in the menu bar.

If you cannot see it, your menu bar may be full. Close a few menu bar items, or check your menu bar manager.

First run

A short welcome shows each display, the way DisplayControl chose to control it, and a Test button. A test changes brightness by a few points, reads it back and restores it.

The window

Click the menu bar icon. Each display has a card with brightness, contrast and volume sliders for the controls it really has. The chevron opens more: input, power, mute, rotation, resolution, control mode, the sync offset and a self-test.

Control modes

ModeWhat it does
DDCTalks to the monitor over its cable using DDC/CI. Changes the real backlight and the other hardware controls.
AppleBuilt-in screens and Apple displays, through macOS.
SoftwareDarkens the picture with gamma. Works on almost anything, including virtual and Sidecar displays, but is not real brightness.

The default is automatic: DDC if the monitor answers, otherwise Apple, otherwise software. You can force a mode per display. A monitor that has just been plugged in is retried after 2, 4 and 8 seconds, because monitors often ignore DDC while the link comes up.

Where things are saved

Settings, presets and schedules are JSON files in ~/Library/Application Support/DisplayControl/. A backup copy is kept, and a damaged file falls back to it.
