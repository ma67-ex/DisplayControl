Features

Each item below exists in the code today. Where something is partial, it says so.

Several displays

Sync makes one display the host and the rest follow, for brightness, contrast and volume. Each follower has an offset: "when the host is at 100 percent, this display is at 70". Followers only change for controls they support.

Presets store exactly what you tick: brightness, contrast, volume, mute, input, power, rotation, resolution, position and sync. They apply in a fixed order so values land on an awake display on the right input. A display that is not connected is skipped, not treated as an error.

Schedules connect triggers to presets. See the schedules guide for the full list.

Keyboard

Optional brightness and volume keys for external displays (needs Accessibility permission), plus custom shortcuts for brightness, contrast, volume, mute, cycling inputs, toggling sync and applying presets.

Automation

  • Command line: displaycontrol status, set, get, preset, schedule, sync, selftest, probe. JSON when piped.
  • URL scheme: displaycontrol://preset/Evening works from Terminal, scripts and any app that opens URLs.
  • MCP server: displaycontrol mcp lets an AI assistant list and change displays and apply presets.
  • Not implemented: native Siri, Spotlight and Shortcuts actions. They would need a full Xcode build. Until then, use the URL scheme or the command line from a Shortcuts "Run Shell Script" action.

Look and feel

  • Light, Night or match the system. One button in the menu bar window cycles through them; the choice is also in Settings, General.
  • A brightness glow. The brightness slider and the display icon glow in proportion to the level: brighter and wider as you raise it, dimmer as you lower it, and nearly white when boosted. Reduce Motion turns the flare off.

Built to be trusted

  • Reads values back after a write and warns when a monitor ignores them.
  • Per-display command queue: a slider drag becomes a few writes, always ending on the final value, spaced to protect monitors.
  • selftest checks a monitor end to end and puts every value back.
  • No network access, no analytics, no account. Open source under the MIT License.

Not included

  • Samsung and LG smart monitor control over Wi-Fi.
  • HDR, True Tone and Night Shift toggles.
  • Brightness beyond a display's normal maximum.
  • DDC on Intel Macs. They get Apple-display control and software dimming.
  • Windows.
