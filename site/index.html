The problem it fixes

Buttons you cannot reach

Monitor menus live behind the bezel, one tiny button at a time. Changing brightness at night should not need a manual.

Screens that do not match

Your laptop panel and your monitor are rarely the same brightness. You end up matching them by eye, again and again.

Settings that reset

Some monitors forget their settings when they reconnect. A schedule can put them back the moment they appear.

How it works

  1. Detects each display. It reads the monitor's own capability list over DDC/CI, the standard that monitor buttons use, and shows only the controls the monitor really has.
  2. Falls back when it must. If a monitor does not answer, DisplayControl can dim it with software gamma instead, and tells you which mode each display is in.
  3. Checks its own work. After a change it reads the value back. If the monitor ignores a setting, you see a hint instead of a silent failure.

What you get

Real hardware control

Brightness, contrast, volume, mute, input source, power and rotation, where the monitor supports them.

Sync

Move one slider and the other displays follow, with an offset so a bright laptop and a dim monitor can still match.

Presets

Save a whole desk setup, including inputs, resolution and arrangement, and apply it in one click.

Schedules

Run a preset at a time, at sunrise or sunset, on wake, on unlock, when you plug in, or when a monitor connects.

Keyboard

Use the brightness and volume keys on the display under your pointer, or record your own shortcuts.

Scriptable

A command line tool, a displaycontrol:// URL scheme and an MCP server for AI assistants.

Light on your Mac

Event driven, with no polling. On the test Mac it sat at 0.0% CPU with the window closed, with a 24 MB memory footprint. It has no network code, no analytics and no account. Read the privacy page.
